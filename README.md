
# Week 7 Assignment: My Notes & The Report Builder

## Description

This assignment practices Python file handling, reading and writing text files, working with CSV data, and handling missing files.

## Project Files

| File Name | Description |
|---|---|
| my_notes.py | Writes, appends, reads, and counts notes. |
| my_notes.txt | Stores the four notes generated by my_notes.py. |
| report_builder.py | Reads learner data and generates a report. |
| hubs.csv | Contains learner names, hubs, and scores. |
| report.txt | Stores the generated learner report. |
| README.md | Documents the assignment and project files. |

## What happens if I change "a" to "w"?

If I change the file mode from "a" to "w", Python will overwrite the existing file content instead of adding to it.

This means the first three notes will be erased when the fourth note is written. Only "I added this later" will remain in the file.
